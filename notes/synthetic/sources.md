# Synthetic Trajectory Generation: Task Sources and Agentic Systems

Overview of failure-attribution methods that generate synthetic trajectories, listing their synthesis mechanism, source task benchmarks, and the agentic systems used to produce trajectories.

| Method (Dataset) | Synthesis Mechanism | Task Sources (Benchmarks) | Agentic Systems Used to Generate Trajectories |
| :--- | :--- | :--- | :--- |
| **AgenTracer** (`TracerTraj-2.5K` / `v1.0.0`, `papers/methods/AgenTracer_2509.03312v2.pdf`) | Counterfactual replay on natural failures + programmatic fault injection into successful runs (DeepSeek-R1) | **Paper:** MBPP+, KodCode, Blackjack *(coding)*; MATH, GSM8K *(math)*; GAIA, HotpotQA *(agentic)*. **Released v1.0.0:** KodCode-V1, MATH-style, ToolQA, web-research (small GAIA subset). | **Paper (6 MAS):** MetaGPT, AutoGen, Smolagents *(manual)*; AgentPrune *(partial)*; AFlow, OWL-Workforce *(automated)*. **Released v1.0.0:** MetaGPT, AFlow, OpenHands (ToolQA) + generic `assistant` web-research runs. |
| **Aegis** (`Aegis` / `Aegis-Bench`, 9,533 traces, `papers/methods/AEGIS_2509.14295.pdf`) | Adaptive LLM manipulator injects 14 MAST modes via prompt injection or response corruption into deterministic GPT-4o-mini runs | MATH, GSM8K *(math)*; HumanEval *(code)*; SciBench *(science)*; MMLU-Pro *(knowledge)*; GAIA *(general assistant; SmolAgents & Magentic-One only)*. | **6 MAS (via MASLab):** MacNet *(chain/star/tree/full)*, DyLAN, LLM Debate, AgentVerse, Magentic-One, SmolAgents. |
| **CORRECT** (`CORRECT-Error`, 2,226 traces, `papers/methods/CORRECT_2509.24088v2.pdf`) | Matches successful traces to Who&When Hand-Crafted failures; GPT-5 plans injection and generator rewrites one step | GAIA *(L1)*, HotpotQA, MuSiQue, 2WikiMultihopQA, ARC, MATH-500, MMLU-Pro. | **1 MAS:** Magentic-One variant in AutoGen (`Planner`, `WebSurfer`, `Coder`, `CodeExecutor`, `FileSurfer`) run with `gpt-5-nano` and `gpt-4o-mini`. |
| **AgentScope** (`AgentErrata`, 303 traces, `papers/methods/AgentScope_2609.02371v1.pdf`) | Taxonomy-guided fault injection (10 modes) via instrumented replay + cross-step consistency post-processing + manual verification | BrowseComp *(web research)*, SWE-Bench Lite *(coding)*, WebArena *(interactive web)*. | **3 stacks:** OpenManus, OWL, Mini SWE Agent. |
| **ParaRecover** (10,626 instances, `papers/methods/ParaRecover_2609.12345v1.pdf`) | Real rollout trajectories + error augmentation across 14 parallel tool-use DAG error types (Level-1 & Level-2) | BUTTON *(compositional atomic tasks arranged as parallel tool DAGs)*. | **Simulated tool-agent environment** (BUTTON tool-agent simulator) rolled out across 10+ LLMs (GPT-4o/5, Claude 4.6, Gemini 3.1, Qwen3). |
| **Who&When Pro — Text Split** (6,257 traces, `data/who_and_when_pro/data/text.jsonl`) | Exact prefix replay + in-distribution base-agent failure injection across 17–18 taxonomy modes | **16 text benchmarks:** TableBench, DSQA, DataBench, SciBench, SimpleQA-Verified, MATH, MMLU-Pro, DABench, ALFWorld, DA-Code, GAIA, BigCodeBench, GPQA, LiveCodeBench-Pro, KramaBench, HumanEval. | **8 text frameworks:** smolagents *(TableBench, DSQA, DataBench, DABench, DA-Code, KramaBench)*, MathChat *(MMLU-Pro, MATH, SciBench)*, Magentic-One *(SimpleQA-Verified, GAIA)*, Multi-Agent Debate *(SciBench, MATH, GPQA, MMLU-Pro)*, ALF-Agent / ReAct *(ALFWorld)*, MacNet *(BigCodeBench, LiveCodeBench-Pro, HumanEval)*, DyLAN *(SciBench, GPQA)*, MetaGPT *(LiveCodeBench-Pro, BigCodeBench)*. |
| **DuoTrace** (`arXiv:2608.29646v2`, `papers/methods/DuoTrace_2608.29646.pdf`) | Synthesizes **normal (successful) trajectories** (rather than injected failures) via *Outcome-Verified Replay* (keep candidate runs passing reference/env checks + deduplicate) and *Root-to-Node Path Extraction* to train its Tree-LSTM VAE anomaly filter | SWE-bench, VitaBench, WebArena *(and other source benchmarks; Sec. 4.1)*. | **LLM trajectory generator** (paper does not specify a fixed MAS scaffold for replay generation—an LLM generates candidate trajectories directly from source queries/context and filters by reference answers or environment success criteria). |
