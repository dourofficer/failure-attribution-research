# Notes layout

Everything [RESEARCHER] writes lives in this folder:

- `datasets/`: the dataset survey (`main.tex` → `main.pdf`), described below.
- `proposals/`: every research proposal, one document each as `pps[0-9][0-9]_<slug>.{tex,pdf}`, plus the conformal case studies; layout below.
- `tutorial/`: the conformal prediction tutorial, cheatsheet and pipeline page.
- `multi_step_datasets.md`: datasets with several labelled error steps per trajectory, broken down by subset (source, system, backbone, label counts).

`WRITER_GUIDE.md` and the tree below call the survey root `report/`, its name before earlier moves; read `report/` as `notes/datasets/`.

Per dataset: `<slug>.tex` is hand-written (template: `3_core/who_and_when/who_and_when.tex`, rules in `WRITER_GUIDE.md`);

`refs.bib` holds the corrected BibTeX entry. `main.tex` pulls a dataset in with `\dataset{<group>}{<slug>}`.
The slug -> group map lives in `scripts/report_layout.py`. Build with `./build.sh`.

## Proposals layout (`proposals/`)

```
proposals/
  pps00_preliminaries        overview of proposals 1-5, the working definition of failure attribution, Table tab:vocab, the shared data engine Table tab:engine
  pps01_counterfactual       proposal 1: counterfactual perturbation screens
  pps02_labelfree            proposal 2: label-free attribution (hazard model)
  pps03_policy-improvement   proposal 3: attribution-guided policy improvement
  pps04_lifecycle            proposal 4: the lifecycle of an error
  pps05_reroll               proposal 5: the restart frontier
  pps06_conformal-training   conformal training for failure attribution (own preamble, not linked to pps00-05)
  case_studies               conformal prediction in failure attribution: case studies (own preamble)
  example.md                 an example proposal from another project
  preamble.tex               shared by pps00-05: a copy of the survey preamble plus the definition / assumption / RQ boxes and the split-document helpers
  refs_proposals.bib, refs_related.bib, refs_training.bib, refs_lifecycle.bib, refs_reroll.bib, refs_survey.bib   bibliography of pps00-05
  refs_conformal.bib, refs_conformal_training.bib   bibliography of case_studies and pps06
  build.sh, build/ (pdflatex aux output, gitignored)
```

Each name above is a `.tex` with its `.pdf` beside it. `./build.sh` builds all of them; `./build.sh <name>...` builds the named ones.

pps00-05 were one document (`8_proposals/proposals.tex` in the survey) and still refer to each other and to the survey. Each is now standalone: the references resolve through xr-hyper from `build/<name>_labels.aux` and from the survey's `../datasets/build/main.aux`, and link to the other PDF. Tables, figures, definitions and assumptions are numbered `n.i` with `n` the document number (0 for the preliminaries), so a number names its document; plain numbers point into the survey. Build the survey first (`../datasets/build.sh`), or its references print as `??`.
