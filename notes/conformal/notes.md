# Conformal training notes

## ConfTr vs DPSM

ConfTr is Stutz et al., "Learning Optimal Conformal Classifiers", ICLR 2022 (`papers/learning-optimal-conformal-classifiers.pdf`). DPSM is Shi et al., "Direct Prediction Set Minimization via Bilevel Conformal Classifier Training", ICML 2025 (`papers/direct-prediction-set-minimization.pdf`). A worked side-by-side in one notation is in `notes/tutorial/conftr-dpsm.html`.

| | ConfTr | DPSM |
| -- | -- | -- |
| **Idea** | Run a differentiable split conformal prediction inside every mini-batch: half the batch calibrates a threshold, the other half is scored against it, and the loss on the resulting soft sets is backpropagated through both halves. | Make the threshold a learned scalar `q`. A bilevel problem: the lower level fits `q` to the (1−α)-quantile of the true-label scores by quantile regression; the upper level minimises cross-entropy plus λ times the soft set size at `q`. |
| **Quantile** | Recomputed from scratch on each batch by smooth sorting of the calibration half's scores. It is a function of the model, so gradients flow through it. Lives for one batch. | One pinball-loss gradient step per iteration, `q ← q − γ(α − fraction of scores ≥ q)`. No sorting. Carried across all iterations; the set-size loss treats it as a constant. |
| **Objective** | `log(mean[L_set + λ·max(0, soft size − κ)])`, where `L_set` is an optional coverage loss on the soft set. No cross-entropy term. | `L_cls + λ·(mean soft size)`, plus the separate pinball update for `q`. Cross-entropy always included. |
| **Data use** | Each mini-batch is split 50/50 afresh into calibration and prediction halves. | The training set is split once into two halves: one feeds cross-entropy and the pinball loss, the other feeds only the size loss (its labels are never used). |
| **Theory** | None for training. Coverage comes only from the ordinary conformal calibration run after training; the paper argues informally that the batch calibration keeps coverage near 1−α in expectation. | Learning bounds on the size loss: error between order 1/s and 1/√s when the quantile is estimated from a batch of size s (ConfTr-style), against order 1/√n when `q` is fit to all n training scores. No convergence proof for the simple algorithm actually used. Coverage also comes only from post-training calibration. |
| **Hyperparameters added** | Sigmoid temperature, smooth-sort dispersion (fixed at 0.1), target size κ, size weight λ, training α. Sensitive to batch size, since the calibration half must be large enough for the α used. | Sigmoid temperature, size weight λ, learning rate γ of `q`, initial `q`, training α. |
| **Extras** | Set shaping through the loss: class-conditional size weights, a loss matrix that penalises specific confusions between classes, and a mis-coverage loss between groups of classes. | None beyond set size. The paper's contribution is the formulation and the bound. |
| **Experiments** | MNIST, F-MNIST, EMNIST, CIFAR10, CIFAR100 at α = 0.01. Trained with the thresholding score on log-probabilities; tested with THR and APS. On CIFAR only a linear layer on pre-trained ResNet features is trained. | CIFAR-100, Caltech-101, iNaturalist with ResNet and DenseNet at α = 0.1. Trained with the HPS score; tested with HPS, APS and RAPS. Baselines: cross-entropy, CUT, ConfTr. |
| **Results** | Set size down 1.8–18.5% with THR and 11.2–32.2% with APS against a cross-entropy baseline (Tab. 1, with `L_set`). Accuracy can be 2–6% lower when training from scratch. | Set size down 20.46% on average against the best baseline per setting (HPS and APS). Gains range from about 2% to 59%, and two APS settings are slightly worse (+8.71%, +0.54%). |
| **Known weak points** | Small batches give a noisy threshold, and training can fail to converge when the calibration half is too small for the chosen α. The paper does not say which smooth sorter or rounding rule it uses. | `q` lags behind the model early in training. The algorithm is a heuristic for the bilevel problem (no hyper-gradient). Several settings are unreported: initial `q`, temperature, batch sizes of the two halves. |
| **Implementation effort** | Needs a differentiable sort and care with the quantile level and batch split. | A scalar parameter, a pinball loss and a second data loader; simpler to write. |
