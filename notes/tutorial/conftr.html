Stutz, Dvijotham, Cemgil & Doucet · ICLR 2022 · Learning Optimal Conformal Classifiers

How conformal training puts conformal prediction inside the training loop

Conformal prediction (CP) turns a trained classifier into a set predictor whose sets contain the true class with probability at least \(1-\alpha\). That guarantee holds for any model, so the only thing a better model can buy is smaller sets. Yet the model is trained with cross-entropy, which never sees a set. Conformal training (ConfTr) runs a smooth copy of CP on every mini-batch and trains the model to shrink the sets that copy produces. After training the copy is thrown away and ordinary CP is calibrated again, so the guarantee is untouched. Figures marked toy use simulated numbers; numbers from the paper name the table or section they come from.

Part 1 · Background · Sec. 1, 2.1

Split conformal prediction: a wrapper added after training

Train the classifier as usual and freeze it. Then choose one threshold on held-out labelled data. The guarantee assumes nothing about the model.

Setting

Where CP sits

training set→ fit \(\pi_\theta\) with cross-entropy→ freeze \(\theta\)→ calibrate \(\tau\) on held-out \(I_{\rm cal}\)→ return \(C(x)\subseteq[K]\) for each test input
  • A classifier \(\pi_\theta(x)\) gives a probability \(\pi_{\theta,k}(x)\) to each class \(k\in[K]=\{1,\dots,K\}\). The paper's main datasets are MNIST, Fashion-MNIST, EMNIST, CIFAR10 and CIFAR100.
  • Instead of one label, CP returns a confidence set \(C(x)\subseteq[K]\), with the guarantee \(\mathbb P\big(Y\in C(X)\big)\ge 1-\alpha\) whenever the calibration examples \((X_i,Y_i),\ i\in I_{\rm cal}\), are exchangeable with the test example.
  • The guarantee is marginal: the probability averages over test inputs and over draws of the calibration set. It is not a promise about each input.
  • Larger sets signal more uncertainty. A poor classifier gives large, uninformative sets.
THR

The threshold predictor in three moves (toy)

Toy classifier

1Score each calibration example

THR (Sadinle et al., 2019) scores class \(k\) by its probability, \(E_\theta(x,k)=\pi_{\theta,k}(x)\). On a calibration example only the true class counts, so its conformity score is the probability the model gives the right answer.

\[ E_\theta(x_i,y_i)=\pi_{\theta,y_i}(x_i),\qquad i\in I_{\rm cal} \]

THR can also threshold logits (THRL) or log-probabilities (THRLP). This choice matters again in Part 3.

Four of the \(n=199\) toy calibration examples. Bars are the 10 class probabilities (classes 0–9); the green triangle marks the true class, and its bar height is the score \(E\).

2Threshold = a low quantile of the scores

Sort the \(n\) scores and take number \(m\) from the bottom. The paper calls this the \(\alpha(1+1/n)\)-quantile; \(m\) below is the index that makes the finite-sample bound hold.

\[ \tau=E_{(m)},\qquad m=\big\lfloor \alpha\,(n+1)\big\rfloor \]

\(m-1\) calibration scores fall below \(\tau\). By exchangeability, a new example's score lands below \(\tau\) with probability \(m/(n+1)\le\alpha\) (for distinct scores), and only then is its true class left out.

true class would be kepttrue class would be left out

3Predict a set for each new input

Every class whose probability clears \(\tau\) goes in. A confident input gets one class, an ambiguous one gets several, and about a fraction \(\alpha\) of inputs lose their true class.

\[ C_\theta(x;\tau)=\{\,k:\ \pi_{\theta,k}(x)\ge\tau\,\} \]
in the setleft outdashed line: \(\tau\)true class
\[ \text{Cover}=\frac{1}{|I_{\rm test}|}\sum_{i\in I_{\rm test}}\delta\big[y_i\in C(x_i)\big],\qquad \text{Ineff}=\frac{1}{|I_{\rm test}|}\sum_{i\in I_{\rm test}}\big|C(x_i)\big| \]

The paper's two metrics (Eq. 2). Averaged over calibration/test splits, Cover \(\approx1-\alpha\) by the guarantee, so methods are compared by inefficiency (Ineff, the average set size; lower is better).

Guaranteed \(\mathbb P\big(Y\in C(X)\big)\ge1-\alpha\), for any classifier, if calibration and test data are exchangeable. Over 4,000 simulated test inputs: coverage (target ). The bound holds on average over calibration draws; with \(n=199\) one draw can be off by about ±0.02. Resample to watch it move.
Not guaranteed Small sets. How large they are depends entirely on the model; CP only picks \(\tau\). Here: Ineff . Both toy classifiers below are calibrated the same way. Coverage barely moves between them; set size does.
APS

Adaptive prediction sets, the other test-time predictor (toy)

APS (Romano et al., 2020) ranks the classes by probability, \(\pi_{\theta,y^{(1)}}(x)\ge\dots\ge\pi_{\theta,y^{(K)}}(x)\). The score of the class at rank \(k\) is the mass ranked above it plus a random share \(U\sim\mathcal U[0,1]\) of its own (Eq. 1). Low score means likely class.

\[ \begin{aligned}E_\theta(x,k)={}&\pi_{\theta,y^{(1)}}(x)+\dots+\pi_{\theta,y^{(k-1)}}(x)\\&+U\,\pi_{\theta,y^{(k)}}(x)\end{aligned} \]
\[ \begin{aligned}C_\theta(x;\tau)&=\{\,k:\ E_\theta(x,k)\le\tau\,\}\\ \tau&=E_{(m)},\quad m=\big\lceil(1-\alpha)(n+1)\big\rceil\end{aligned} \]

Because low is good here, the paper calibrates APS at the \((1-\alpha)(1+1/n)\)-quantile. On a fixed baseline model THR gives the smallest sets (paper Fig. 2, CIFAR10, \(\alpha=0.01\): Ineff 3.92 THRL, 2.93 THR, 3.30 APS, 3.06 RAPS); APS was designed for better conditional coverage.

Toy test input \(x_1\) from above. Its class probabilities are laid end to end, most likely first; the black tick in each segment is that class's score \(E_\theta(x,k)\). Classes whose tick is left of \(\tau\) form the set.

Part 2 · Motivation · Sec. 1

The mismatch: trained for one label, used as a set predictor

Calibration pins coverage whatever \(\theta\) is. What is left for the model to get right is set size, and cross-entropy never sees it.

What training optimises

one labelled example \((x,y)\)↓ \(\pi_\theta(x)\)↓ \(\ell_{\rm CE}=-\log\pi_{\theta,y}(x)\)↓ \(\nabla_\theta\,\ell_{\rm CE}\)
No threshold, no set, no \(\alpha\). Each example asks only that its one label be likely.

What deployment measures

frozen \(\pi_\theta\)↓ \(\tau\) from held-out \(I_{\rm cal}\)↓ \(C(x)=\{k:\pi_{\theta,k}(x)\ge\tau\}\)↓ Cover \(\approx 1-\alpha\) (fixed by CP) · Ineff (depends on \(\theta\))
No gradient ever passes through \(\tau\) or \(C(x)\).
Consequence Since every calibrated model covers, the better conformal classifier is the one with smaller sets. In the paper's words, the model parameters are "not informed about the post-hoc conformalization", so they are not tuned to reduce inefficiency.
Concurrent work: Bel Bellotti (2021), "Bel" in the results, learns a set predictor by thresholding logits (THRL) at a fixed \(\tau\), e.g. \(\tau=1\), which works because logits are unbounded. It uses a squared coverage loss per batch, \(\big[\tfrac{1}{|B|}\sum_{i\in B}C_{\theta,y_i}(x_i;\tau)-(1-\alpha)\big]^2\), plus a size loss with \(\kappa=0\) (App. E). Bel differentiates through prediction only and skips calibration during training. ConfTr also differentiates through calibration, which the paper calls crucial for reducing inefficiency further.
Part 3 · Method · Sec. 2.2, 3.1 · Fig. 1a · Alg. 1

ConfTr: simulate CP on every mini-batch

Each update splits the batch, calibrates a threshold on one half, predicts soft sets on the other half and penalises their size. The gradient reaches \(\theta\) through both halves.

Fig. 1a

One training update, and the two routes the gradient takes

Show

Solid grey arrows: forward pass. Dashed: the gradient of the loss flowing back to \(\theta\). Route ① runs through the soft sets' dependence on the predictions \(\pi_\theta(x)\), \(x\in B_{\rm pred}\). Route ② runs through their dependence on \(\tau\), and from \(\tau\) through SmoothCal into the predictions \(\pi_\theta(x_i)\), \(i\in B_{\rm cal}\). The paper's Fig. 1a labels these "diff. w.r.t. \(\theta\) through \(\pi_\theta(x_i)\) and \(\tau\)" and "through \(\pi_\theta(x_i)\)".

1Split the batch

\[ B=B_{\rm cal}\uplus B_{\rm pred}\quad\text{(random halves)} \]
Soft sets are computed only on \(B_{\rm pred}\), never on \(B_{\rm cal}\), so the half that sets \(\tau\) is not the half being scored: the same separation as calibration and test in Part 1.

2SmoothCal: a differentiable threshold

\[ \tau=\mathrm{SmoothQuant}\Big(\{E_\theta(x_i,y_i)\}_{i\in B_{\rm cal}},\ \alpha\big(1+\tfrac{1}{|B_{\rm cal}|}\big)\Big) \]
Any smooth sorting method works (Blondel et al., 2020; Cuturi et al., 2019; Williamson, 2020). Its dispersion \(\varepsilon\to0\) recovers hard sorting; the paper fixes \(\varepsilon=0.1\) (Table B). Now \(\tau\) has a gradient with respect to \(\pi_\theta(x_i)\), \(i\in B_{\rm cal}\).

3SmoothPred: soft membership

\[ C_{\theta,k}(x;\tau)=\sigma\!\Big(\frac{E_\theta(x,k)-\tau}{T}\Big)\in[0,1],\quad x\in B_{\rm pred} \]
Read \(C_{\theta,k}\) as the probability that class \(k\) is in the set. Temperature \(T\to0\) recovers the hard set. In the paper's runs \(E_\theta(x,k)=\log\pi_{\theta,k}(x)\) (THRLP).

4Size loss and objective

\[ \Omega\big(C_\theta(x;\tau)\big)=\max\Big(0,\ \sum_{k=1}^{K}C_{\theta,k}(x;\tau)-\kappa\Big) \]
\[ \min_\theta\ \log\mathbb E\big[\Omega(C_\theta(X;\tau))\big] \]
\(\kappa=1\) by default, so a singleton costs nothing; \(\kappa\in\{0,1\}\) is a hyper-parameter (Table B picks 0 for some runs without \(\mathcal L_{\rm class}\)). Per batch the expectation is the mean over \(B_{\rm pred}\). Alg. 1 writes the gradient of that mean; Eq. (3)–(4) and the code in App. P take its log.
Why calibrate inside the loop With a fixed \(\tau\), the size loss alone is minimised by empty sets, so a coverage loss must balance it, and \(\tau\) must be guessed in advance, which the paper found hard for THR and APS (App. E). Recomputing \(\tau\) on \(B_{\rm cal}\) at every update keeps coverage on \(B_{\rm pred}\) near \(1-\alpha\) (in expectation over batches, for \(T,\varepsilon\to0\) and large enough \(|B_{\rm cal}|\)), so ConfTr only needs to minimise size. One way to see it: pushing every score down by the same amount drags \(\tau\) down by that amount and leaves \(\Omega\) unchanged. The only way to shrink sets is to move wrong-class scores below the true-class scores of the hardest calibration examples.

Part 4 · Sec. 2.2

Hard versus smooth: what makes CP differentiable

Thresholding and sorting have zero or undefined gradients. ConfTr swaps each for a smooth stand-in with one knob: temperature \(T\) for prediction, dispersion \(\varepsilon\) for calibration. As \(T,\varepsilon\to0\) the hard versions come back.

Toy batch

One simulated batch: \(|B_{\rm cal}|=39\), one \(B_{\rm pred}\) input, \(\alpha=0.1\)

paper grid

Scores are log-probabilities, \(E_\theta(x,k)=\log\pi_{\theta,k}(x)\), as in the paper's training runs (THRLP). The toy uses \(\alpha=0.1\) because 39 calibration scores cannot resolve the paper's \(\alpha=0.01\).

1SmoothPred: indicator → sigmoid

The hard set uses an indicator; ConfTr uses a sigmoid. Each class gets a soft membership, and their sum is a soft set size. Lower \(T\) sharpens the sigmoid toward the indicator, but then classes away from \(\tau\) get almost no gradient.

\[ \begin{aligned}C_{\theta,k}(x;\tau)&=\sigma\!\Big(\frac{E_\theta(x,k)-\tau}{T}\Big)\\&\xrightarrow[T\to0]{}\ \delta\big[E_\theta(x,k)\ge\tau\big]\end{aligned} \]

The paper searched \(T\in\{0.01,0.1,0.5,1\}\) and found it mattered little; in the MNIST ablation \(T=0.01\) was worst (Ineff 2.39) and \(T=1\) best (2.18) (Table D).

hard indicator at \(\tau\)sigmoid at \(\tau_\varepsilon\), current \(T\)paper grid \(T\)true class

2SmoothCal: hard quantile → smooth quantile

Sort the 39 true-class scores and read position \(m\). The smooth version reads the same position from a soft sort. Here that is the soft sort of Blondel et al. (2020) with quadratic regularisation, one of the methods the paper cites. Sorted scores whose gaps are small compared with \(1/\varepsilon\) stay put; across larger gaps it pools runs of scores into blocks, whose outputs sit evenly spaced around the block's mean. \(\tau_\varepsilon\) then depends equally on every score in its block.

\[ \begin{aligned}\tau&=E_{(m)},\qquad m=\lfloor\alpha(n+1)\rfloor\\ \tau_\varepsilon&=\big[\mathrm{SoftSort}_\varepsilon\big(\{E_\theta(x_i,y_i)\}_{i\in B_{\rm cal}}\big)\big]_m\end{aligned} \]

For small enough \(\varepsilon\) this soft sort is exactly the hard sort. As \(\varepsilon\to\infty\) every output tends to the mean score, so \(\tau_\varepsilon\) drifts away from the \(\alpha\)-quantile: coverage during training is only approximate. The paper does not name the method its runs use and fixes its dispersion at \(\varepsilon=0.1\) (Table B), on a scale not comparable with this toy's \(\varepsilon\).

Top row: the scores, hard-sorted, with \(\tau\) at position \(m\) (ringed). Middle row: the soft-sorted values, joined to their hard counterparts. Bottom: \(\partial\tau_\varepsilon/\partial E_\theta(x_i,y_i)\), the share of the threshold each calibration example controls: \(1/|\text{block}|\) inside \(\tau_\varepsilon\)'s block, 0 outside. The shares sum to 1, because shifting every score shifts \(\tau_\varepsilon\) by the same amount.

3The gradient, by both routes

Both stand-ins are smooth, so \(\Omega\) has a gradient with respect to every score in the batch. It arrives by the two routes of the diagram in Part 3.

① \( \displaystyle \frac{\partial\Omega}{\partial E_\theta(x,k)}=\frac{C_{\theta,k}(1-C_{\theta,k})}{T} \)
② \( \displaystyle \frac{\partial\Omega}{\partial E_\theta(x_i,y_i)}=\frac{\partial\Omega}{\partial\tau}\cdot\frac{\partial\tau_\varepsilon}{\partial E_\theta(x_i,y_i)} \)
\( \displaystyle \quad \frac{\partial\Omega}{\partial\tau}=-\sum_k\frac{C_{\theta,k}(1-C_{\theta,k})}{T} \)

Gradient descent moves against these. Route ① lowers the \(B_{\rm pred}\) scores that sit near \(\tau\). Route ② raises the true-class scores of the calibration examples that set \(\tau\). Since \(\Omega\) depends on scores only through \(E-\tau\), the two routes carry equal and opposite totals.

Shown for \(\Omega\) of one \(B_{\rm pred}\) input (with \(\kappa=1\)), with respect to scores. The training loss is the log of the batch mean, which rescales these; backpropagation through \(\pi_\theta\) then carries them to \(\theta\).

① via predictions, per class of the \(B_{\rm pred}\) input② via \(\tau\), per \(B_{\rm cal}\) example
Part 5 · Sec. 3.2–3.3 · Eq. 4–8 · Fig. 1b

Beyond size: a classification loss that shapes the sets

Size alone says nothing about which classes end up together. A loss on the soft sets can.

Eq. 5

\(\mathcal L_{\rm class}\) and the loss matrix \(L\) (toy, after Fig. 1b)

ConfTr can add any loss \(\mathcal L\) on the sets (Eq. 4). The paper's choice is a configurable classification loss \(\mathcal L_{\rm class}\) (Eq. 5), steered by a loss matrix \(L\):

\[ \min_\theta\ \log\Big(\mathbb E\big[\mathcal L(C_\theta(X;\tau),Y)+\lambda\,\Omega(C_\theta(X;\tau))\big]\Big) \]
\[ \mathcal L_{\rm class}(C_\theta(x;\tau),y)=\sum_{k=1}^{K}L_{y,k}\Big[\underbrace{(1-C_{\theta,k}(x;\tau))\,\delta[y=k]}_{\text{enforce } y \text{ to be in } C}+\underbrace{C_{\theta,k}(x;\tau)\,\delta[y\ne k]}_{\text{penalise } k\ne y \text{ in } C}\Big] \]
0 gives \(L=I_K\)

With \(L=I_K\) only the first term is active: the loss is \(1-C_{\theta,y}\), which enforces coverage and is zero only when the true class is fully in. This is the "\(+\mathcal L_{\rm class}\)" column of Table 1. An entry \(L_{y,k}>0\), \(y\ne k\), charges for including class \(k\) when the truth is \(y\).

soft membership \(C_{\theta,k}\)penalty \(L_{y,k}C_{\theta,k}\)coverage gap \(1-C_{\theta,y}\)

Toy soft set for a cat image (\(y=\) cat), CIFAR10 classes, names shortened. The bottom row is the loss-matrix row \(L_{\text{cat},k}\). Above the dashed line (\(C=0.5\), where \(E=\tau\)) the hard set is {cat, dog, truck}, as in the paper's Fig. 1b, where penalising vehicles gives class loss \(0+1\) and the figure shows size \(|C|=3\).

Sec. 3.3

Three ways to shape the sets

The paper motivates these with medical diagnosis: less ambiguity on some conditions, fewer sets that mix two often-confused diseases, or no high-risk condition inside a low-risk patient's set.

Loss matrix

Coverage is still guaranteed and accuracy stays roughly the same, so pushing one pair apart usually raises confusion elsewhere.

\(L_{y,y}\): enforce coverage\(L_{y,k}>0\): penalise \(k\) when truth is \(y\)

(a) Class- or group-conditional inefficiency

\[ \text{Ineff}[Y{=}y]=\frac{\sum_{i}\delta[y_i{=}y]\,|C(x_i)|}{\sum_{i}\delta[y_i{=}y]} \]
Eq. 6. Tool: weight the size loss of Eq. (3) by the true class, \(\omega(Y)\cdot\Omega\). Paper (Fig. 3, \(\omega=10\)): reductions of 20% or more for many CIFAR10 classes, including the hard class "cat"; also for groups (vehicles vs. animals); more than 30% when targeting one of CIFAR100's 20 coarse groups (5 classes each). Cost: average Ineff over all classes rises slightly.

(b) Coverage confusion

\[ \Sigma_{y,k}=\frac{1}{|I_{\rm test}|}\sum_{i}\delta\big[y_i{=}y\wedge k\in C(x_i)\big] \]
Off-diagonals: how often \(k\) is in the set when the truth is \(y\) (Eq. 7). Tool: \(L_{y,k}>0\). Paper (Fig. 4, Fashion-MNIST): coverage confusion of coat (4) and shirt (6) drops by roughly 1%, while that of pullover (2) with coat (4) can rise.

(c) Mis-coverage between groups

\[ \text{MisCover}_{0\to1}=\frac{\sum_{i}\delta\big[y_i\in K_0\wedge C(x_i)\cap K_1\ne\emptyset\big]}{\sum_{i}\delta[y_i\in K_0]} \]
How often a set for a \(K_0\) example contains a \(K_1\) class (Eq. 8). Tool: \(L_{y,k}>0\) for \(y\in K_0,\ k\in K_1\). Paper (Fig. 5): CIFAR10 with \(K_0=\{\)cat\(\}\): 98.92% → 91.60%. CIFAR100 human-made (35 classes) vs. natural (65): 40.09% → 15.77%, but Ineff rises from 10.44 to 16.50.
Part 6 · Sec. 2.2, 3.1 · App. C

After training: back to ordinary CP

The training-time threshold and the smooth stand-ins are discarded. A standard, hard CP method is calibrated on held-out data, and that is where the guarantee comes from.

Test time

ConfTr changes inefficiency, not validity

ConfTr-trained \(\pi_\theta\)→ training \(\tau\)SmoothCalSmoothPred→ calibrate THR or APS (hard quantile) on held-out \(I_{\rm cal}\)→ \(C(x)\) with \(\mathbb P(Y\in C(X))\ge1-\alpha\)

"After training, any CP method can be applied to re-calibrate \(\tau\) on a held-out calibration set \(I_{\rm cal}\) as usual, i.e., the thresholds \(\tau\) obtained during training are not kept" (Sec. 3.1). The smooth stand-ins only approximate coverage, exactly only as \(T,\varepsilon\to0\); that does not matter, because they are never used at test time (Sec. 2.2). The test-time predictor need not match the training one: Table 1 trains with THRLP and tests with THR or APS.

Unchanged: validity \(\mathbb P\big(Y\in C(X)\big)\ge1-\alpha\) from the hard calibration on \(I_{\rm cal}\), under the usual conditions (App. C): calibration examples exchangeable with test examples, and a learning algorithm invariant to permutations of the training examples. With distinct scores it is near tight, \(\le 1-\alpha+\frac{1}{|I_{\rm cal}|+1}\). MNIST, \(\alpha=0.01\), THR, 10 training runs (Table C): coverage 99.09% baseline, 99.03% ConfTr, 99.05% ConfTr + \(\mathcal L_{\rm class}\).
Changed: efficiency and composition Same runs: Ineff 2.23 → 2.18 → 2.11; accuracy 92.4% → 90.2% / 91.2%. With the losses of Part 5, also which classes share a set and how inefficiency is spread across classes.

Practice

What the paper reports about making it work

Train with THRLP, whatever the test-time predictor Every ConfTr model in Table 1 is trained with THR on log-probabilities, also when APS is used at test time. Training with THR or APS directly was hard, likely from limited gradient flow through probabilities (Sec. 4.1, App. I). On MNIST, ConfTr trained with APS reached Ineff 5.79 ± 3.1 across training runs, against 2.18 ± 0.025 with THRLP (Table C). Since \(\log\) is monotone, hard THR on log-probabilities returns exactly the same sets as on probabilities. The choice only changes the gradients of the smooth stand-ins.
CIFAR: only a linear layer is trained On CIFAR, ConfTr trains a linear model on top of a pre-trained ResNet (ResNet-34 for CIFAR10, ResNet-50 for CIFAR100), whose features never see conformalization. THR gains are therefore small (−3.1%, −1.8%); APS gains stay large (−11.2%, −23.4%).
Accuracy can drop ConfTr does not necessarily recover the baseline's accuracy (of the arg max prediction). Trained from scratch it can be 2–6% lower while still reducing inefficiency, which the paper reads as cross-entropy training not being appropriate for CP. MNIST: 92.4% → 90.2% (Table C).
Batch size matters most MNIST ablation of ConfTr without \(\mathcal L_{\rm class}\) (Table D): with \(|B|=500\) or 1000, Ineff 2.17–2.27; with \(|B|=100\), so \(|B_{\rm cal}|=50\), it fails to converge (Ineff 7.32–9.66, accuracy 11.5–22.46%). The paper's explanation: too few calibration examples for \(\alpha=0.01\). Size weight \(\lambda\) and \(T\) had little effect; \(\varepsilon\) is fixed at 0.1. Table B's chosen MNIST setting with \(\mathcal L_{\rm class}\) does use \(|B|=100\).

Lower \(\alpha\) at test time, with ConfTr still trained at \(\alpha=0.01\) (Table 2, EMNIST, THR): Ineff 4.10 → 3.37 (−17.8%) at \(\alpha=0.005\), and 15.73 → 13.65 (−13.2%) at \(\alpha=0.001\).
