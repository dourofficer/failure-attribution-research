DPSM, original: a classifierEncoder on frozen step vectors
Bilevel problem \[ \begin{aligned}&\min_{\theta,\,q}\ \widehat{\mathcal L}_{\rm cls}(\theta)+\lambda\,\widehat{\mathcal L}^{\rm DM}_c(\theta,q)\\ &\ \text{s.t.}\ \ q\in\mathcal U(\theta)\triangleq\arg\min_{q'}\widehat{\mathcal L}^{\rm QR}(\theta,q')\end{aligned} \] \[ \begin{aligned}&\min_{\theta,\,q}\ \widehat{\mathcal L}_{\rm cls}(\theta)+\lambda\,\widehat{\mathcal L}_{\rm size}(\theta,q)\\ &\ \text{s.t.}\ \ q\in\mathcal U(\theta)\triangleq\arg\min_{q'}\widehat{\mathcal L}^{\rm QR}(\theta,q')\end{aligned} \]
Input and candidates an input \(X\); candidate labels \(y\in\mathcal Y\), the same \(K\) classes for every input a failed trajectory \(x=(s_1,\dots,s_T)\), a task and \(T\) agent turns; candidate steps \(t\in[T]=\{1,\dots,T\}\), with \(T\) different for each trajectory
Label one true class \(Y\in\mathcal Y\) a non-empty error set \(Y\subseteq[T]\); every step in \(Y\) is a valid answer
Model a network \(f_\theta\) with softmax output \(f_\theta(X)_y\) over \(\mathcal Y\); every parameter in \(\theta\) is trained \[ \begin{aligned}h_t&=\tfrac{1}{|I_t|}\textstyle\sum_{j\in I_t}H_j\quad\class{df}{\text{(frozen LLM, cached)}}\\ u_t&=Wh_t+e^{\rm agent}_{a(t)}+e^{\rm pos}_t\\ (v_1,\dots,v_T)&=\mathrm{Enc}_\phi(u_1,\dots,u_T)\\ \pi_t(x)&=\frac{\exp(w^\top v_t)}{\class{df}{\sum_{t'=1}^{T}}\exp(w^\top v_{t'})}\end{aligned} \] \(H_j\): hidden state of token \(j\); \(I_t\): the tokens of step \(t\); \(a(t)\): the agent of step \(t\); \(\mathrm{Enc}_\phi\): a two-layer transformer encoder. Trained: \(\theta=(W,e^{\rm agent},e^{\rm pos},\phi,w)\); the LLM stays frozen.
Score \(S_f(X,y)=1-f_\theta(X)_y\) \(S_\theta(x,t)=1-\pi_t(x)\)
True-label score \(S_f(X,Y)\) \(\class{df}{S^{\min}_\theta(x,Y)=\min_{t\in Y}S_\theta(x,t)}=1-\max_{t\in Y}\pi_t(x)\); the set \(\{t: S_\theta(x,t)\le q\}\) contains a step of \(Y\) exactly when \(S^{\min}_\theta(x,Y)\le q\)
Classification loss \(\widehat{\mathcal L}_{\rm cls}(\theta)=\frac1n\sum_{i=1}^n-\log f_\theta(X_i)_{Y_i}\) \(\widehat{\mathcal L}_{\rm cls}(\theta)=\frac1n\sum_{i=1}^n-\log\class{df}{\sum_{t\in Y_i}}\pi_t(x_i)\)
Size loss (upper level) \(\widehat{\mathcal L}^{\rm DM}_c(\theta,q)=\frac1n\sum_{i=1}^n\sum_{y\in\mathcal Y}\tilde{\mathbf 1}\big[S_f(X_i,y)\le q\big]\) \(\widehat{\mathcal L}_{\rm size}(\theta,q)=\frac1n\sum_{i=1}^n\class{df}{\sum_{t=1}^{T_i}}\tilde{\mathbf 1}\big[S_\theta(x_i,t)\le q\big]\)
Quantile loss (lower level) \(\widehat{\mathcal L}^{\rm QR}(\theta,q)=\frac1n\sum_{i=1}^n\rho_\alpha\big(q,\,S_f(X_i,Y_i)\big)\) \(\widehat{\mathcal L}^{\rm QR}(\theta,q)=\frac1n\sum_{i=1}^n\rho_\alpha\big(q,\,\class{df}{S^{\min}_\theta(x_i,Y_i)}\big)\)
Training data \(\mathcal D_{\rm tr}\), \(n\) labelled inputs, split once at random into halves \(\mathcal D_1,\mathcal D_2\) of size \(n/2\) \(\mathcal D_{\rm tr}\), \(n\) labelled trajectories, split once by task into \(\mathcal D_1,\mathcal D_2\)
After training \(q\) is discarded; split conformal prediction on \(\mathcal D_{\rm cal}\) with the scores \(S_f(X_i,Y_i)\) gives \(\mathcal C_f(X)=\{y: S_f(X,y)\le\widehat Q_f(\alpha)\}\), which covers when \(Y\in\mathcal C_f(X)\) \(q\) is discarded; split conformal prediction on \(\mathcal D_{\rm cal}\) with the scores \(\class{df}{S^{\min}_\theta(x_i,Y_i)}\) gives \(\mathcal C_\theta(x)=\{t\in[T]: S_\theta(x,t)\le\widehat Q(\alpha)\}\), which covers when \(\class{df}{\mathcal C_\theta(x)\cap Y\neq\varnothing}\)
The same in both \[ \rho_\alpha(q,S)=\begin{cases}(1-\alpha)(S-q), & S\ge q\\ \alpha\,(q-S), & \text{otherwise}\end{cases}\qquad \frac{\partial}{\partial q}\,\frac{1}{|\mathcal B|}\sum_{i\in\mathcal B}\rho_\alpha(q,S_i)=\alpha-\frac{\#\{i: S_i\ge q\}}{|\mathcal B|} \] \[ \tilde{\mathbf 1}\big[S\le q\big]=\frac{1}{1+\exp\!\big(-(q-S)/\tau_{\rm Sigmoid}\big)}\qquad\text{(soft membership, temperature }\tau_{\rm Sigmoid}\text{)} \]

Data and gradient flow in one iteration (original work)

One gradient step on \(\theta\) and one pinball step on \(q\) per iteration.

DPSM, Algorithm 1, in this page's notation
1:Input: \(\mathcal D_{\rm tr}\), \(\lambda\), learning rates \(\eta,\gamma>0\), miscoverage \(\alpha\)
2:randomly initialise \(\theta_0\) and \(q_0\in\mathbb R\)
3:randomly split \(\mathcal D_{\rm tr}\) into disjoint \(\mathcal D_1,\mathcal D_2\), \(|\mathcal D_1|=|\mathcal D_2|=\tfrac n2\)
4:for \(t\leftarrow0:T-1\) do
5:sample batches \(\mathcal B^1_t\subset\mathcal D_1,\ \mathcal B^2_t\subset\mathcal D_2\)
6:\(\widehat\nabla_{\theta,t}\leftarrow\widehat\nabla_\theta\widehat{\mathcal L}_{\rm cls}(\theta_t)\) on \(\mathcal B^1_t\)
7:\(\widehat\nabla^{\rm QR}_{q,t}\leftarrow\widehat\nabla_q\widehat{\mathcal L}^{\rm QR}(\theta_t,q_t)\) on \(\mathcal B^1_t\)
8:\(\widehat\nabla^{\rm DM}_{\theta,t}\leftarrow\widehat\nabla_\theta\widehat{\mathcal L}^{\rm DM}_c(\theta_t,q_t)\) on \(\mathcal B^2_t\)
9:\(\theta_{t+1}\leftarrow\theta_t-\eta\big(\widehat\nabla_{\theta,t}+\lambda\,\widehat\nabla^{\rm DM}_{\theta,t}\big)\)
10:\(q_{t+1}\leftarrow q_t-\gamma\,\widehat\nabla^{\rm QR}_{q,t}\)
11:end for
12:Output: the trained model \(f_{\theta_T}\)
  • Gradients. Line 8 is the partial derivative in \(\theta\) with \(q\) held fixed: no hyper-gradient \(\partial q^*/\partial\theta\). The \(\theta\)-gradient of the pinball loss is not used, and the size loss sends no gradient to \(q\).
  • Data. The split is done once (line 3). \(\mathcal D_1\) feeds cross-entropy and the pinball loss; \(\mathcal D_2\) feeds only the size loss, which sums over all labels, so the labels of \(\mathcal D_2\) are never used.
  • Indices. All three gradients are read at the current iterate \((\theta_t,q_t)\); the paper prints \(f_{t-1},q_{t-1}\) in lines 6–8.
  • Output is \(f_{\theta_T}\) alone: \(q_T\) is discarded and split conformal prediction is run on \(\mathcal D_{\rm cal}\).

Data and gradient flow in one iteration (encoder on frozen step vectors setting)

The same iteration, with the steps of a trajectory as the candidates.

values, forward passgradientsstate kept between iterationsdiffers from the originalfrozen, no gradient
Algorithm 1 for the encoder on frozen step vectors
1:Input: \(\mathcal D_{\rm tr}=\{(x_i,Y_i)\}\), error sets \(Y_i\subseteq[T_i]\), step vectors \(h_t\) cached from one pass of the frozen LLM, \(\lambda\), learning rates \(\eta,\gamma>0\), miscoverage \(\alpha\)
2:randomly initialise \(\theta_0=(W,e^{\rm agent},e^{\rm pos},\phi,w)\) and \(q_0\in\mathbb R\)
3:split \(\mathcal D_{\rm tr}\) once, by task, into disjoint \(\mathcal D_1,\mathcal D_2\)
4:for \(k\leftarrow0:N-1\) do
5:sample batches \(\mathcal B^1_k\subset\mathcal D_1,\ \mathcal B^2_k\subset\mathcal D_2\)
6:\(\widehat\nabla_{\theta,k}\leftarrow\widehat\nabla_\theta\widehat{\mathcal L}_{\rm cls}(\theta_k)\) on \(\mathcal B^1_k\) ▷ \(-\log\sum_{t\in Y_i}\pi_t(x_i)\)
7:\(\widehat\nabla^{\rm QR}_{q,k}\leftarrow\widehat\nabla_q\widehat{\mathcal L}^{\rm QR}(\theta_k,q_k)\) on \(\mathcal B^1_k\) ▷ scores \(S^{\min}_\theta(x_i,Y_i)\)
8:\(\widehat\nabla^{\rm size}_{\theta,k}\leftarrow\widehat\nabla_\theta\widehat{\mathcal L}_{\rm size}(\theta_k,q_k)\) on \(\mathcal B^2_k\) ▷ \(T_i\) terms per trajectory
9:\(\theta_{k+1}\leftarrow\theta_k-\eta\big(\widehat\nabla_{\theta,k}+\lambda\,\widehat\nabla^{\rm size}_{\theta,k}\big)\)
10:\(q_{k+1}\leftarrow q_k-\gamma\,\widehat\nabla^{\rm QR}_{q,k}\)
11:end for
12:Output: the trained encoder \(f_{\theta_N}\)
  • Unchanged. One plain gradient step on \(\theta\) and one pinball step on \(q\) per iteration, \(q\) held fixed in the size loss, no hyper-gradient, and the labels of \(\mathcal D_2\) never used.
  • Frozen features. The LLM runs once per trajectory before training; its step vectors \(h_t\) are constants, so the gradient ends at \(W\), \(e^{\rm agent}\) and \(e^{\rm pos}\) and never reaches the LLM.
  • Set-valued label. Cross-entropy is the negative log of the mass on \(Y_i\); the pinball loss sees \(S^{\min}_\theta(x_i,Y_i)\), the score of the error step that a set reaches first.
  • Variable length. The softmax and the soft size run over the \(T_i\) steps of each trajectory, so a long trajectory adds more terms to \(\widehat{\mathcal L}_{\rm size}\).
  • Split by task. No task appears in both \(\mathcal D_1\) and \(\mathcal D_2\).
  • Notation. The iteration index is \(k\) and the number of iterations \(N\), because \(t\) and \(T\) now denote a step and the trajectory length.
  • Output is \(f_{\theta_N}\) alone: \(q_N\) is discarded and split conformal prediction is run on \(\mathcal D_{\rm cal}\) with the scores \(S^{\min}_\theta\).
