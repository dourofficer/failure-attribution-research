Learnable conformal prediction · ConfTr (Stutz et al., ICLR 2022) · DPSM (Shi et al., ICML 2025)

Training a classifier for small conformal sets: ConfTr and DPSM in one notation

Both methods train the network to produce small prediction sets, and both finish with ordinary split conformal prediction, so the coverage guarantee comes from that final step, not from training. They differ in the threshold they use while training. ConfTr runs a smoothed conformal prediction on every mini-batch: half the batch sets the threshold through a smooth sort, the other half is scored against it, and the gradient flows back through both halves. DPSM makes the threshold a separate scalar parameter \(q\), learned by quantile regression on one half of the training data, while the set size is measured on the other half with \(q\) held fixed. Both sections below run on the same toy mini-batch, and every number in them is computed in your browser from the formulas shown.

Background, used by both

Split conformal prediction in three sentences

Both algorithms end with this step, unchanged. Training only decides which model goes into it.

(1) A non-conformity score \(S_f(X,y)\) measures how badly a candidate label \(y\) fits the input \(X\) under the trained model; this page uses \(S_f(X,y)=1-f_\theta(X)_y\), one minus the softmax probability (DPSM's HPS score). (2) On a held-out calibration set \(\mathcal D_{\rm cal}\) of \(m\) labelled examples, compute each true-label score \(S_i=S_f(X_i,Y_i)\) and set the threshold \(\widehat Q_f(\alpha)\) to their \(\lceil(1-\alpha)(m+1)\rceil\)-th smallest value, a slightly conservative \((1-\alpha)\)-quantile (the value below which a fraction \(1-\alpha\) of the scores lie). (3) The prediction set of a new input is every label whose score is at most \(\widehat Q_f(\alpha)\), and if calibration and test examples are exchangeable it contains the true label with probability at least \(1-\alpha\) for any model; that probability is the coverage, and \(\alpha\) is the miscoverage level.

\[ \widehat Q_f(\alpha)=S_{(k)},\ \ k=\big\lceil(1-\alpha)(m+1)\big\rceil;\qquad \mathcal C_f(X)=\{y\in\mathcal Y:\ S_f(X,y)\le\widehat Q_f(\alpha)\};\qquad \mathbb P\{Y\in\mathcal C_f(X)\}\ge1-\alpha \]

Because the guarantee holds for any model, training cannot break it. What a better-trained model buys is a smaller set size \(|\mathcal C_f(X)|\), the number of labels in the set; its average over test inputs is what ConfTr calls inefficiency. Both algorithms below train \(f_\theta\) so that this number is small.

✓Toy calibration, \(m=19\)

Raise \(\alpha\) and the threshold drops, so sets shrink and can even be empty; lower it and they grow. This is the post-training step of both methods.

Where the two papers use opposite conventions, and what this page does
  1. Score direction. ConfTr uses conformity scores \(E_\theta(x,k)\), high when the label fits (for its threshold predictor THR, the probability \(\pi_{\theta,k}(x)\) itself); its set is \(\{k: E_\theta(x,k)\ge\tau\}\), and \(\tau\) is a low quantile (level \(\alpha\)) of the calibration scores. DPSM uses non-conformity scores \(S_f(X,y)\), high when the label fits badly; its set is \(\{y: S_f(X,y)\le q\}\), and \(q\) is a high quantile (level \(1-\alpha\)). This page uses DPSM's convention throughout. To translate, use \(S=1-E\) and \(q=1-\tau\) for THR (this makes THR exactly DPSM's HPS score), or \(S=-E\) and \(q=-\tau\) for THR on log-probabilities (THR LP), the score ConfTr actually trains with. Either way \(E-\tau=q-S\), so ConfTr's \(\sigma\big((E-\tau)/T\big)\) is literally DPSM's \(\tilde{\mathbf 1}[S\le q]\) with \(\tau_{\rm Sigmoid}=T\).
  2. Quantile level. ConfTr calibrates at the \(\alpha(1+1/n)\)-quantile of conformity scores (\(n\) = calibration size); DPSM takes the \(\lceil(1-\alpha)(1+m)\rceil\)-th smallest non-conformity score. With the downward rounding natural for a low quantile, ConfTr's level selects the \(\lfloor\alpha(m+1)\rfloor\)-th smallest \(E\), which is exactly the \(\lceil(1-\alpha)(m+1)\rceil\)-th smallest \(S\): the same test-time threshold. For ConfTr's smooth training quantile the page mirrors the level to \(1-\alpha(1+1/|\mathcal B_{\rm cal}|)\) on \(S\). That is not \((1-\alpha)(1+1/|\mathcal B_{\rm cal}|)\), which exceeds 1 for small batches.
  3. Letters that clash. \(T\) is ConfTr's temperature and DPSM's number of iterations, so the temperature is written \(\tau_{\rm Sigmoid}\). \(\tau\) is ConfTr's threshold but a dummy variable and the temperature's letter in DPSM, so ConfTr's training threshold is \(\hat q_f\), the name DPSM itself gives it. ConfTr's Alg. 1 uses \(n\) for the calibration size; DPSM's \(n\) is the training-set size, so calibration size is \(m\). \(\sigma\) is ConfTr's sigmoid and DPSM's penalty weight (Eq. 10), so the page writes \(\tilde{\mathbf 1}[\cdot]\). \(\epsilon\) is ConfTr's sorting dispersion and a DPSM tolerance, so the page uses \(\varepsilon_{\rm sort}\). Both papers say "classification loss", but ConfTr's \(\mathcal L_{\rm class}\) is a loss on the soft set and DPSM's \(\mathcal L_{\rm cls}\) is cross-entropy, so ConfTr's is renamed \(\mathcal L_{\rm set}\).
  4. Model or parameters. DPSM writes its losses as functions of the model, \(\widehat{\mathcal L}(f,q)\), and its Algorithm 1 updates \(f\) directly. The page writes \(\widehat{\mathcal L}(\theta,q)\) for \(\widehat{\mathcal L}(f_\theta,q)\) and updates \(\theta\), as ConfTr does.
  5. DPSM's summary of ConfTr. DPSM's appendix restates ConfTr's objective (its Eq. 14) as a plain average soft set size, without ConfTr's \(\kappa\) and without the logarithm. The ConfTr section below uses ConfTr's own Eqs. 3–5.
Shared by both

The soft prediction set

Both papers replace the 0/1 set membership by a sigmoid, so that set size has a gradient.

The hard set size \(\sum_y\mathbf 1[S_f(X,y)\le q]\) is a staircase in the scores: nudging a score changes nothing until it crosses \(q\), so its gradient is zero almost everywhere. Both papers swap each step for a sigmoid:

\[ \begin{aligned}\tilde{\mathcal C}_{f,y}(X;q)&=\tilde{\mathbf 1}\big[S_f(X,y)\le q\big]\\ &=\frac{1}{1+\exp\!\big(-(q-S_f(X,y))/\tau_{\rm Sigmoid}\big)}\\ \text{soft size}&=\textstyle\sum_{y\in\mathcal Y}\tilde{\mathcal C}_{f,y}(X;q)\end{aligned} \]

The temperature \(\tau_{\rm Sigmoid}\) sets the width of the transition: a label whose score lies a few \(\tau_{\rm Sigmoid}\) below \(q\) counts as fully in, a few above as fully out, and \(\tau_{\rm Sigmoid}\to0\) gives back the hard set. ConfTr calls this step SMOOTHPRED (temperature \(T\)); DPSM writes \(\tilde{\mathbf 1}\) (Eq. 4). The two papers differ only in where \(q\) comes from.

1Calibrate on \(\mathcal B_{\rm cal}\), smoothly

Take the true-label scores of rows 1–8 and read off a high quantile. A hard quantile is a sorted entry: it moves with one score only and jumps when two scores swap places. Smooth sorting replaces the sorted vector with a nearby one that changes continuously with every score; its dispersion \(\varepsilon_{\rm sort}\) controls how far it may depart from the hard sort (\(\varepsilon_{\rm sort}\to0\) is the hard sort). Reading the quantile off it makes \(\hat q_f\) a smooth function of \(\theta\).

\[ \begin{aligned}\hat q_f&=\mathrm{SmoothQuant}_{\varepsilon_{\rm sort}}\big(\{S_f(X_i,Y_i)\}_{i\in\mathcal B_{\rm cal}};\ p\big)\\ p&=1-\alpha\big(1+\tfrac{1}{|\mathcal B_{\rm cal}|}\big)\end{aligned} \]

Top: the eight scores (row numbers above). Middle: the smooth sort; shaded groups were pooled by the sorter and move together. Bars: \(\partial\hat q_f/\partial S_i\), the share of the threshold's gradient each calibration example receives (the shares sum to 1). Small \(\varepsilon_{\rm sort}\): only the two scores around the level are touched. Large: the share spreads and \(\hat q_f\) slides toward the mean score.

2Predict soft sets on \(\mathcal B_{\rm pred}\)

Every label of every row 9–16 gets a soft membership at the threshold just computed (line 7). Nothing is predicted on \(\mathcal B_{\rm cal}\): the half that set the threshold is not scored against it.

\[ \tilde{\mathcal C}_{f,y}(X_i;\hat q_f)=\tilde{\mathbf 1}\big[S_f(X_i,y)\le\hat q_f\big]\quad\big(i\in\mathcal B_{\rm pred},\ y\in\mathcal Y\big) \]

3Loss on the soft sets

The size loss charges each soft set for the size above \(\kappa\); with \(\kappa=1\), singletons are free. The optional coverage loss charges for leaving the true label out (ConfTr's \(\mathcal L_{\rm class}\) with the identity loss matrix; other loss matrices shape the sets and are not covered here).

\[ \begin{aligned}\Omega(X)&=\max\Big(0,\ \textstyle\sum_{y\in\mathcal Y}\tilde{\mathcal C}_{f,y}(X;\hat q_f)-\kappa\Big)\\ \mathcal L_{\rm set}(X,Y)&=1-\tilde{\mathcal C}_{f,Y}(X;\hat q_f)\\ \mathcal L(\theta)&=\log\Big(\tfrac{1}{|\mathcal B_{\rm pred}|}\textstyle\sum_{i\in\mathcal B_{\rm pred}}\big[\mathcal L_{\rm set}(X_i,Y_i)+\lambda\,\Omega(X_i)\big]\Big)\end{aligned} \]

The last line is Eq. 4; without \(\mathcal L_{\rm set}\) it is Eq. 3 up to the constant \(\log\lambda\).

Without \(\mathcal L_{\rm set}\), \(\lambda\) multiplies everything inside the log and drops out of the gradient: move \(\lambda\) and step 4 does not change. The paper reports the same (App. H: \(\lambda\) "merely scales the learning rate").

Coverage is not a training target here Without \(\mathcal L_{\rm set}\), the objective only shrinks sets. ConfTr relies on the calibration half for coverage: \(\hat q_f\) is recomputed from the current model on every batch, so a model that shrinks sets by lowering confidence on true labels also raises \(\hat q_f\). The paper: "in expectation across mini-batches and large enough \(|B_{\rm cal}|\), for \(T,\epsilon\to0\), CP guarantees coverage \(1-\alpha\) on \(B_{\rm pred}\)."

4Backpropagate through both halves

The loss depends on \(\theta\) through two routes: the scores of \(\mathcal B_{\rm pred}\) directly, and the threshold \(\hat q_f\), which is a function of the scores of \(\mathcal B_{\rm cal}\). Automatic differentiation follows both:

\[ \begin{aligned}\frac{\partial\mathcal L}{\partial S_f(X_j,Y_j)}&=\frac{\partial\mathcal L}{\partial\hat q_f}\cdot\frac{\partial\hat q_f}{\partial S_f(X_j,Y_j)}\qquad(j\in\mathcal B_{\rm cal})\\ \nabla_\theta\mathcal L&=\textstyle\sum_{\text{all scores }S}\frac{\partial\mathcal L}{\partial S}\,\nabla_\theta S,\qquad \theta\leftarrow\theta-\eta\,\nabla_\theta\mathcal L\end{aligned} \]

DPSM: learn the threshold as a parameter, by quantile regression

The threshold becomes a single scalar \(q\), trained alongside the network. A bilevel problem says what \(q\) must be, and Algorithm 1 takes one plain gradient step on \(\theta\) and one on \(q\) per iteration.

Problem

The bilevel formulation

A bilevel problem is an optimisation problem whose constraint is itself an optimisation problem. In DPSM's upper level, the network (and \(q\)) are chosen to minimise classification loss plus \(\lambda\) times the soft set size at threshold \(q\). The lower level requires \(q\) to minimise the pinball loss of the true-label scores, which makes \(q\) their \((1-\alpha)\)-quantile under the current network (Eq. 8):

\[ \min_{\theta,\,q}\ \widehat{\mathcal L}_{\rm cls}(\theta)+\lambda\,\widehat{\mathcal L}^{\rm DM}_c(\theta,q)\qquad\text{s.t.}\qquad q\in\mathcal U(\theta)\triangleq\arg\min_{q'}\widehat{\mathcal L}^{\rm QR}(\theta,q') \] \[ \widehat{\mathcal L}^{\rm DM}_c(\theta,q)=\frac1n\sum_{i=1}^n\sum_{y\in\mathcal Y}\tilde{\mathbf 1}\big[S_f(X_i,y)\le q\big]\ \ \text{(Eq. 9)},\qquad \widehat{\mathcal L}^{\rm QR}(\theta,q)=\frac1n\sum_{i=1}^n\rho_\alpha\big(q,\,S_f(X_i,Y_i)\big) \]

The pinball loss is a tilted absolute error: a score above \(q\) costs \(1-\alpha\) per unit of distance, a score below costs \(\alpha\) per unit. Its average is smallest where a fraction \(\alpha\) of the scores lie above \(q\), that is, at their \((1-\alpha)\)-quantile (Eq. 7). Its slope in \(q\) is \(\alpha\) minus the fraction of scores at or above \(q\), so a gradient step needs no sorting.

\[ \rho_\alpha(q,S)=\begin{cases}(1-\alpha)(S-q), & S\ge q\\ \alpha\,(q-S), & \text{otherwise}\end{cases}\qquad \frac{\partial}{\partial q}\,\frac{1}{|\mathcal B|}\sum_{i\in\mathcal B}\rho_\alpha(q,S_i)=\alpha-\frac{\#\{i: S_i\ge q\}}{|\mathcal B|} \]

The size term is ConfTr's soft set size without \(\kappa\) and without the logarithm, and the classification term is ordinary cross-entropy.

Why learn \(q\) rather than sort the batch: DPSM proves that the size loss evaluated at a quantile taken from a batch of \(s\) examples is off from its value at the true quantile \(Q_f\) by an error between order \(1/s\) and order \(1/\sqrt s\) (Thm. 3.5), while with \(q\) fit to all \(n\) training scores the error is of order \(1/\sqrt n\) (Thm. 4.1), and usually \(s\ll n\).

3Where the gradient goes

\(\theta\) receives cross-entropy from rows 1–8 and \(\lambda\) times the size gradient from rows 9–16; \(q\) receives only the pinball slope. With \(q_t\) a constant in the size loss, rows 1–8 get no gradient from the set size at all, which is the main structural difference from ConfTr's step 4.

4\(q\) is carried across iterations

To isolate the threshold, freeze \(\theta\) and repeat only line 10 for 300 iterations, each on a fresh batch of 8 drawn from \(\mathcal D_1\) (here a pool of 400 true-label scores that includes rows 1–8). The learned \(q\) settles near the \((1-\alpha)\)-quantile of the whole pool, with jitter that grows with \(\gamma\), while the quantile of each single batch, the kind of threshold ConfTr computes, scatters widely. In real training \(\theta\) moves too, so \(q\) tracks a moving target.

DPSM: Algorithm 1 outputs \(f_{\theta_T}\) only; \(\widehat Q_f(\alpha)\) is computed on \(\mathcal D_{\rm cal}\) by Eq. 2. The paper trains with HPS and calibrates with HPS, APS or RAPS.

This is the procedure of the primer at the top of the page, so both trained models get coverage of at least \(1-\alpha\) on exchangeable test data. Neither training procedure carries a guarantee of its own; training changes only how large the sets are.
