Zhu, Wu, Jin, Li & Huang · KDD 2026 · StepFinder (arXiv:2606.03467)

How StepFinder turns a failed trajectory into one root-cause step

StepFinder does not ask an LLM to read the log and reason about it. An embedding model turns every step into two vectors, one for what was said and one for which agent said it. A small trained network (a BiLSTM and one attention layer, about 0.28M parametersfrom code) then gives every step a score, and two terms with no weights of their own adjust it: a bonus for a sudden jump in the step representation and a penalty that grows with lateness. The predicted decisive step is the arg-max \(\hat t\). Only the step is predicted, not the agent.

Names, sentences and numbers in the figures are a toy example (six steps, three agents), computed live from the paper's formulas; only values called "paper" come from the paper. A from code tag marks a detail taken from the official repository (github.com/taiyu-zhu/StepFinder, commit 48d71c7) that the paper does not state; the few places where the code differs from an equation are said so in the note.

From steps to a score per step

One trajectory of \(T\) steps goes in. Every stage keeps one row per step, so the output is \(T\) scores, and the prediction is the largest.

Stage a

Trajectory encoding: two vectors per step

Each step is a pair \(x_t=(c_t,r_t)\): the content the agent produced at step \(t\), and the agent's identity. Both strings go through Qwen3-Embedding-0.6B. Content becomes a 128-d vector, identity a 32-d vector.

\[ \mathbf c_t=\mathrm{Enc}(c_t)\in\mathbb R^{128},\qquad \mathbf r_t=\mathrm{Enc}(r_t)\in\mathbb R^{32} \] \[ \mathbf C\in\mathbb R^{T\times128},\qquad \mathbf R\in\mathbb R^{T\times32} \]

This is the only place a language model is used, and it generates no text. \(\mathbf C\) is the main signal and goes into stage (b). \(\mathbf R\) skips stage (b) and enters at stage (c).

from code The encoder is frozen and run once, offline; the trained model reads cached vectors. Each step is embedded on its own: only that step's content string, with no task question, no ground truth and no neighbouring steps. Pooling is the last token. The 128-d and 32-d vectors are the first 128 and 32 coordinates of the 1024-d embedding (Matryoshka-style truncation), not a learned projection. \(r_t\) is the agent's name string (e.g. "WebSurfer"), so all steps of one agent share the same \(\mathbf r_t\).

Toy trajectory. The decisive error is step 3 (the wrong year's report), but the model is not told that. Same agent, same name string, so rows of \(\mathbf R\) repeat exactly; rows of \(\mathbf C\) all differ.

Stage b

Temporal feature extraction: a BiLSTM over the content

LayerNorm, then a 2-layer bidirectional LSTM (hidden size 64 per direction, dropout 0.5), then LayerNorm again. Each step's state is the forward and backward halves stacked, so \(\mathbf h_t\in\mathbb R^{128}\).

\[ \hat{\mathbf C}=\mathrm{LN}(\mathbf C) \] \[ \mathbf h_t=\big[\overrightarrow{\mathrm{LSTM}}(\hat{\mathbf c}_t);\ \overleftarrow{\mathrm{LSTM}}(\hat{\mathbf c}_t)\big] \] \[ \mathbf H_{out}=\mathrm{LN}(\mathbf H),\quad \mathbf H=\{\mathbf h_t\}_{t=1}^{T} \]

The forward half summarises steps \(1..t\), the backward half steps \(t..T\). A step that looks fine on its own but leads to the failure later can be judged with what came after it.

from code Only the content sequence enters the BiLSTM; agent vectors are not concatenated to it. Sequences are packed, so padding is skipped.

Unrolled over the six toy steps (one layer shown). Highlighted: everything that reaches \(\mathbf h_3\). The forward chain brings steps 1–3, the backward chain steps 6–3.

Stage c

Agent-aware step interaction: attention plus agent identity

1Self-attention with an agent bias

Multi-head self-attention over all steps (2 heads, 32 dims per head), so any step can draw on any other, not only its neighbours. Before the softmax, the cosine similarity of the two steps' agent vectors is added, scaled by \(\alpha\). Padded steps are masked out.

\[ \mathbf Q,\mathbf K,\mathbf V=\mathbf H_{out}W_Q,\ \mathbf H_{out}W_K,\ \mathbf H_{out}W_V \] \[ \mathbf E=\frac{\mathbf Q\mathbf K^{\top}}{\sqrt{d_k}},\qquad B_{ij}=\cos(\mathbf r_i,\mathbf r_j) \] \[ \mathbf{Attn}=\mathrm{softmax}(\mathbf E+\alpha\,\mathbf B) \] \[ \mathbf H_{attn}=\mathbf H_{out}+\mathbf{Attn}\,\mathbf V \]

from code A single attention layer, with no feed-forward block and no LayerNorm after it. \(W_Q,W_K,W_V\) map 128 to 64 dims (2 × 32, no bias), and an output projection \(W_O\) (64 to 128) brings the result back, so the residual is \(\mathbf H_{out}+W_O(\mathbf{Attn}\,\mathbf V)\). Both heads get the same \(\alpha\mathbf B\). Padded keys are set to \(-10^9\) before the softmax.

The bias matrix \(\mathbf B\) for the toy trajectory. A pair of steps by the same agent always gets 1, the largest possible cosine. Values between different agents are toy. With paper settings \(\alpha=0.1\) (Alg) or \(0.3\) (HC), the bias moves a logit by at most \(\alpha\).

2Agent gate

The mean agent vector \(\bar{\mathbf r}\) summarises which team ran. A sigmoid layer maps it to \(\mathbf g\in(0,1)^{128}\), which scales the features, with the same \(\alpha\) as in the bias.

\[ \bar{\mathbf r}=\frac1T\sum_{t=1}^{T}\mathbf r_t,\qquad \mathbf g=\sigma(W_g\bar{\mathbf r}+b_g) \] \[ \mathbf H_{final}=\mathbf H_{attn}\odot(1+\alpha\,\mathbf g) \]

\(\bar{\mathbf r}\) is one vector per trajectory, so every step gets the same \(\mathbf g\). The gate rescales feature channels, by a factor between 1 and \(1+\alpha\); it does not single out any step.

from code \(\bar{\mathbf r}\) is the mean over valid (unpadded) steps; \(W_g\) maps 32 to 128 dims. \(\alpha\), like \(\beta\) and \(\gamma\) below, is a fixed hyperparameter, not learned.

Toy gate. Each column of \(\mathbf H_{attn}\) is multiplied by the same factor \(1+\alpha g_k\) in every row. Drawn with \(\alpha=1\) so the effect is visible; with the paper's \(\alpha\) it is at most 10% (Alg) or 30% (HC).

Stage d

Step-level error scoring: learned score, jump bonus, early-step prior

1Learned score \(\ell_t\)

A two-layer MLP with GELU maps each row of \(\mathbf H_{final}\) to one number.from code 128 → 64 → 1.

\[ \boldsymbol\ell=W_2\,\mathrm{GELU}\big(W_1\mathbf H_{final}+b_1\big)+b_2\ \in\mathbb R^{T} \]

2Jump score \(\Delta_t\): multi-scale differencing

For each scale \(s\) in \(\mathcal S=\{1,2\}\), measure how far the step representation moves, divide by its mean over the trajectory, and average over scales. No parameters are learned here.

\[ D^{(s)}_t=\big\|\mathbf h_t-s\,\mathbf h_{t-1}+(s-1)\,\mathbf h_{t-s}\big\|_2 \] \[ \tilde D^{(s)}_t=\frac{D^{(s)}_t}{\frac1T\sum_{t=1}^{T}D^{(s)}_t+\epsilon},\qquad \Delta_t=\frac{1}{|\mathcal S|}\sum_{s\in\mathcal S}\tilde D^{(s)}_t \]

With \(s=1\) this is the step length \(\|\mathbf h_t-\mathbf h_{t-1}\|\). With \(s=2\) it is \(\|\mathbf h_t-(2\mathbf h_{t-1}-\mathbf h_{t-2})\|\), the distance from where the last move would have landed if continued.

from code The paper writes \(\mathbf h_t\); the code differences the rows of \(\mathbf H_{final}\), after attention and gate (the paper's Figure 2 draws it there too). The first \(s\) steps, which have no \(\mathbf h_{t-s}\), get \(D^{(s)}_t=0\), and the mean is over the trajectory's valid steps.

A 2-d stand-in for the 128-d rows \(\mathbf h_t\) of \(\mathbf H_{final}\). At step 3 the path jumps and turns. The solid red segment is \(D^{(1)}_3\); the dashed red segment, from the straight-line guess \(2\mathbf h_2-\mathbf h_1\) to \(\mathbf h_3\), is \(D^{(2)}_3\).

3Position bias and the final arg-max

A fixed linear prior that favours earlier steps: 0 at the first step, \(-1\) at the last. Then the three terms are added and the largest wins.

\[ b_t=-\frac{t-1}{T-1},\qquad t=1,\dots,T \] \[ \ell^{\rm final}_t=\ell_t+\beta\,\Delta_t+\gamma\,b_t,\qquad \hat t=\arg\max_t\ \ell^{\rm final}_t \]

The paper's reason for \(b_t\): later anomalies are often consequences of an earlier mistake, and a model trained on step features alone tends to blame late steps.

from code Differs from Eq. 9: the code divides by \(T_{\max}-1\), where \(T_{\max}\) is the padded length of the batch (its longest trajectory). For a trajectory shorter than that, \(b_t\) stops above \(-1\) at its last step. For the toy trajectory scored on its own, as here, the two agree.

Training only

How the scores are learned

Supervised: every training trajectory carries the index of its root-cause step. One auxiliary head adds a self-supervised loss and is dropped at test time.

Training

Synthetic failures, a softmax over steps, and a next-state loss

1Training data: regenerated failures

The test sets are the official Who&When subsets: 126 Algorithm-Generated (Alg) and 58 Hand-Crafted (HC) trajectories. Training data are synthetic. The multi-agent system is run on separate training tasks; then an LLM rewrites each failed run with the same question, ground-truth answer and agent team, but a different reasoning path and a different root-cause error. It writes down the root-cause step and agent as it generates, which gives the label.

The paper states that training and test tasks are disjoint. Hyperparameters differ per subset (Table 1 below).

from code In the released data the split is not fully disjoint: 15 of the 126 Alg test questions and 2 of the 58 HC test questions also appear in the training set, with the same ground truth (270 and 36 training runs).

from code The regenerated runs are written, not executed: the LLM writes every turn, including the other agents' and the tool or terminal output. Each has exactly one labelled mistake step. One model is trained per subset. The question and ground truth are stored with each run but never given to the model.

2Classification loss: softmax over the valid steps

The final scores of one trajectory are treated as logits of a \(T\)-way classification, and the target is the labelled step \(y_i\). Padding added to batch trajectories of different lengths is excluded from the softmax. \(B\) is the batch size.

\[ \mathcal L_{\rm CE}=-\frac1B\sum_{i=1}^{B}\log\frac{\exp\big(\ell^{\rm final}_{i,y_i}\big)}{\sum_{j\in\mathcal T_i}\exp\big(\ell^{\rm final}_{i,j}\big)} \]

The loss is taken on \(\ell^{\rm final}\), so \(\beta\Delta_t+\gamma b_t\) is already in place while \(\ell_t\) is learned. At test time the same scores are used and \(\hat t\) is the arg-max over valid steps.

from code Padded logits are set to \(-10^9\), then a standard cross-entropy against the index of the mistake step.

The toy trajectory in a batch padded to 8 steps, with the current \(\beta,\gamma\) and the scores of stage (d) (paper's \(b_t\) with \(T=6\); the code would use \(T_{\max}=8\) here). Bars are softmax probabilities over the 6 valid steps; the label is \(y=3\).

3Temporal consistency loss and the total

A small head \(f_\theta\) predicts each step's state from the previous one. Its error, averaged over steps 2 to \(T\), is added with weight \(\lambda\).

\[ \hat{\mathbf h}_{t+1}=f_\theta(\mathbf h_t) \] \[ \mathcal L_{\rm temporal}=\frac{1}{T-1}\sum_{t=2}^{T}\big\|\hat{\mathbf h}_t-\mathbf h_t\big\|_2^2 \] \[ \mathcal L_{\rm total}=\mathcal L_{\rm CE}+\lambda\,\mathcal L_{\rm temporal} \]

The head only shapes \(\mathbf h_t\) during training. At test time it is removed, and its prediction error is not part of the score.

from code As in stage (d), \(\mathbf h_t\) is a row of \(\mathbf H_{final}\). \(f_\theta\) is Linear(128→128), GELU, Linear(128→128), and the target \(\mathbf h_t\) is detached (no gradient through it). Differs from Eq. 12: the squared error is summed over the 128 dims and divided by the number of valid step positions in the whole batch, rather than averaged per trajectory over its \(T-1\) steps.

Each \(\mathbf h_{t-1}\) predicts \(\hat{\mathbf h}_t\), which is compared with the actual \(\mathbf h_t\). Step 1 has no prediction, hence \(T-1\) terms.
