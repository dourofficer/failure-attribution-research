\paragraph{Description} MegaRCA-Mix is a small, deliberately hard root-cause-attribution test set for \emph{very long} single-agent executions: 50 failed trials with a median log of 286\,K tokens (1.05 MiB), each shipped with the full evidence bundle a human debugger would have --- raw trajectory, trial configuration, agent-side console logs, verifier output and sandbox artifacts. Alongside TRAIL (median 100\,K tokens, 430 KiB) and TELBench (median 39\,K tokens, 144 KiB, stored as per-span files on disk), it is the largest and richest multi-artifact long-horizon setting the paper evaluates on, contrasting with short single-file benchmarks (AgentRx at 7.2\,K tokens; Who\&When algorithm-generated at 2.4\,K tokens) where little search is needed. The paper's method, \emph{Continual Search}, prompts an LLM judge for up to four turns to keep opening unread artifacts before committing to a diagnosis.
\begin{itemize}
\item \textbf{Source}: failed trials from Harbor Index (29 benchmarks across seven domains); the 50-trial mixture spans GAIA, SWE-Bench, HLE, OpenRCA and 15 additional benchmarks (19 represented in total). Per-benchmark, per-domain and per-model composition of the 50 trials is not reported.
\item \textbf{Agent}: Claude Code with Opus-4.8 and GPT-5.5 backbones, run sandboxed under the Harbor framework with its verifiers. Failures are natural.
\end{itemize}
\textbf{Annotation}: each trial is human-annotated with its \emph{first consequential error} under the interaction-centric taxonomy of Raj et al.: a triple (\emph{edge} between the model and an interacting component, \emph{fault side} --- model vs.\ surrounding component, \emph{failure mode} out of 41) plus a quoted first-divergence citation. Gold is stored as one or more \emph{acceptable cluster sets} per trial. Number of annotators, their background and agreement are not reported. \textbf{Taxonomy} (41 role-specific modes across nine component edges; 36 model-side and five non-model-side): model--owner (Over/Under-initiative, Satisficing, Instruction-Following, Reasoning, Unauthorized Irreversible Action, Sycophancy, Domain Knowledge Deficit, Value Misalignment; owner-side \emph{Instruction--Grader Mismatch}), model--grader (Specification Gaming, Evaluation Awareness), model--third party (Indirect Prompt Injection, Contextual Sycophancy), model--context (State Tracking, Goal Drift; context-side \emph{Context Rationale Erosion}), model--memory (Missed Write/Read, State Staleness, Overgeneralization, Memory Rationale Erosion, Pollution, Redundancy, Memory Following Failure), model--tool (Incorrect Selection, Tool Hallucination, Feedback Neglect, Recovery Failure, Malformed/Suboptimal Arguments; tool-side \emph{Mistranslation}), model--peer/subagent (Delegation, Communication), model--external environment (Recovery Failure; environment-side \emph{Service Failure}, \emph{Stale State Delivery}), and model--local environment (Observation/Recovery Failure). Five modes therefore blame a surrounding component rather than the model; four of these (\emph{Instruction--Grader Mismatch}, \emph{Mistranslation}, \emph{Service Failure}, \emph{Stale State Delivery}) target benchmark-side defects.

\paragraph{Metrics and baselines} The judge (Claude Agent SDK with \code{Bash}, \code{Grep}, \code{Glob}, \code{Write}, \code{Edit} and \code{Task} tools) outputs JSON \{\code{trial\_id}, \code{task\_id}, \code{edge}, \code{fault\_side} (\code{model}, \code{owner}, \code{env}, \code{orchestrator}, \code{tool}, \code{grader}, \code{third party}, \ldots), \code{failure\_mode}, \code{first\_divergence}, \code{evidence\_quote}, \code{rationale}, \code{changed\_from\_turn1} / \code{changed\_from\_prev}\} with exact strings from \code{taxonomy.py}. Score: per-trial set-F1 between the predicted cluster set and each acceptable gold set, $F_1(A,B)=2|A\cap B|/(|A|+|B|)$, max over gold sets, averaged over 50 trials (paper Table 2, after four judge turns):

Evidence coverage for Opus-4.8 (Figure 9): 70.5\% of relevant artifacts opened at turn 1 for both strategies; Continual Search reaches 95.2\% (turn 3) and 98.5\% (turn 4) while passive continuation plateaus at 75.6\%. Config files, console logs and raw session records are opened only in later turns, and these are what fix misdiagnoses. On the Section 6 benchmark-defect auditing task over the same 50 trials, Opus-4.8 Continual Search reaches 0.67 F1 (1.00 precision, 0.50 recall across turns 2--4), up from 0.10 at turn 1 and above the dedicated ABA baseline (0.63 F1).

\paragraph{Schema} Not observable. From the paper, a trial = Claude Code session trajectory + \code{config.json} / trial configuration + console logs + verifier/grader output + sandbox artifacts, with gold = acceptable set(s) of (\code{edge}, \code{fault\_side}, \code{failure\_mode}) and a first-divergence citation. There is no agent-role label (Claude Code is single-agent with sub-agents) and the ``step'' is a cited divergence point rather than an index.

\paragraph{Notes} (i) Unreleased: a \emph{described} benchmark only --- cite the numbers but do not count it among usable datasets; the paper's experiments on released data use TRAIL, AgentRx and Who\&When (all covered elsewhere in this survey) plus TELBench (not covered here). (ii) What is unique on paper: the longest traces of any RCA set; a multi-file evidence bundle that turns attribution into a search problem; an interaction-centric fault-side taxonomy (model vs.\ owner, context/harness, tool, or environment) in which five modes blame surrounding components and four specifically target \emph{benchmark-side} defects --- a category almost no other dataset admits; multiple acceptable gold sets scored by set-F1 instead of single-step exact match. (iii) Caveats: only 50 trials; annotation protocol and agreement unreported; no per-benchmark, per-domain or per-model composition tables. (iv) Lineage: built on Harbor Index (Terminal-Bench team) and the Raj et al.\ taxonomy; TRAIL (long traces, including multi-agent GAIA, with a category taxonomy) and AgentRx (shorter single-agent traces with a failure taxonomy) are the closest released analogues.
