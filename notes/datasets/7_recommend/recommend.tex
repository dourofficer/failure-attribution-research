\section{Cross-cutting observations and recommendations}\label{sec:reco}

\paragraph{No two datasets agree on what a ``step'' is} Who\&When counts every message, including orchestrator thoughts and the human question; TraceElephant counts trace events including tool I/O; TRAIL uses OpenTelemetry spans; MemTrace uses memory operations; AgentRx indexes 1-based from the system message; TracerTraj mixes 0- and 1-based indices across domains. Any evaluation that pools datasets must normalise the indexing explicitly---the example trajectories rendered in each section keep the dataset's own numbering for this reason.

\paragraph{Agent naming is a hidden evaluation knob} Agent-level accuracy is exact string match, yet names are inconsistent inside datasets (\code{WebSurfer}/\code{Websurfer} in Who\&When, \code{Assistant}/\code{assistant} in AgentRx) and generic in others (TracerTraj's agentic split labels every step \code{assistant}, making agent-level accuracy trivial). Normalise case and collapse orchestrator variants before scoring.

\paragraph{Single root cause is a modelling choice} Who\&When, TracerTraj, CORRECT-Error and LongRCA store one decisive step. MP-Bench shows three experts agree unanimously on only 16.2\% of union flagged steps (56.1\% have only 1 of 3 votes); AgentRx records multiple failure \emph{events} plus a root cause (root $\ne$ first failure in 26.0\% of public records after ID-type normalisation); TRAIL labels every error span; MegaRCA scores a \emph{set} of (edge, fault, mode) triples with F1. For evaluation, report a window-tolerant step metric alongside exact match, and prefer MP-Bench or AgentRx when the method produces several candidates.

\paragraph{Natural versus injected} Human-labelled natural failures (Who\&When, TraceElephant, MP-Bench, LongRCA, AgentRx, SymFail, TRAIL; $\approx$2.6\,k trajectories before deduplicating Who\&When overlaps in MP-Bench and AgentRx) are the only trustworthy \emph{test} sets. Injected datasets (Who\&When Pro, Aegis, TracerTraj, CORRECT-Error; $\approx$28\,k) are the only practical \emph{training} sets, but their error-position and error-type distributions are skewed (Fig.~\ref{fig:errpos}): Aegis is near-uniform over 14 modes by design and injects near the start on MacNet (mean 0.23), Who\&When Pro and CORRECT-Error concentrate labels at the last step, and TracerTraj is bimodal (mid-trajectory and final step, mean 0.52). Evaluate cross-distribution.

\paragraph{Observation level matters} Output-only logs (Who\&When, MAST-Data) hide tool inputs, screenshots and environment state. TraceElephant reports up to +76\% relative step-attribution accuracy from full traces and ships runnable agent systems and passive tracing middleware (though its Dynamic Agentic counterfactual-replay code is not yet released); LongRCA keeps $\approx$182\,k characters per trajectory; MemTrace stores complete execution graphs (up to 532\,MB per file). Decide early whether the attributor is meant to work from logs or from live replay.

\paragraph{Label provenance} Human-labelled datasets are Who\&When, TraceElephant, MP-Bench, LongRCA, AgentRx, SymFail, TRAIL, AgentErrorBench, SearchAuditBench, Failure-as-a-Process, TrajErrBench, AgentHallu, MemTrace and MegaRCA-Mix. MAST-Data (14 modes) and HORIZON are labelled by an LLM judge (MAST paper validates on 21 traces with $\kappa\approx0.88$; the released human JSON holds 19 traces); Aegis and CORRECT-Error labels are correct by construction but describe injected, not observed, errors.

\paragraph{Recommended protocol}
\begin{enumerate}[leftmargin=1.2em]
\item \textbf{Standard evaluation}: Who\&When (both subsets), TraceElephant (full-trace) and MP-Bench (multi-annotator); report agent accuracy, exact-step accuracy, and step accuracy within $\pm k$ steps.
\item \textbf{Scale / long traces}: add Who\&When Pro (26 benchmarks, 3 modalities) and LongRCA (median 145 steps; use LongRCA-Mini for screening).
\item \textbf{Training}: TracerTraj and Aegis (both with train/val/test splits); CORRECT-Error as a third, Magentic-style source. Hold out one natural dataset for cross-distribution testing.
\item \textbf{Diagnosis beyond ``who/when''}: MAST-Data for failure-mode classification, TRAIL for span-level multi-error localisation, AgentRx for taxonomy + root cause on tool-calling agents.
\item \textbf{Generalisation checks}: AgentErrorBench (embodied/web), SearchAuditBench (deep search), Failure-as-a-Process (CLI coding), AgentHallu (hallucination), MemTrace (memory).
\item \textbf{Licensing}: several datasets carry no explicit dataset license (Who\&When HF card---though its GitHub code repo is MIT---LongRCA, TracerTraj, SearchAuditBench, Failure-as-a-Process, HORIZON); AgentRx and HORIZON-tasks are gated; MegaRCA-Mix and AgentErrata (and parts of AgentRx) are not public as of October 2026. Verify before redistribution.
\end{enumerate}
